# 执行步骤

## 总体原则

- 每阶段完成后验证通过再进入下一阶段
- 优先保证稳定性，再追求功能完善
- 每个阶段结束将产出记录到开发日志

---

## 第一阶段：环境搭建

**目标**：Rust + Slint 工具链就绪，空项目可编译运行

### 步骤

1. 安装 VSCode + Rust 扩展（rust-analyzer、CodeLLDB、Slint 插件）
2. 安装 rustup + stable 工具链
3. 创建 Cargo 项目骨架，配置 release 优化参数（LTO、strip、panic=abort）
4. 引入 Slint，创建最小无框窗口
5. 引入 TinySkia，画布渲染空白页
6. 引入 rusqlite，初始化数据库（创建 4 张表）
7. 编译运行，验证"窗口 + 渲染 + 存储"三件套

### 产出

- 可编译运行的空白窗口程序
- 项目目录结构就绪
- 开发日志记录

---

## 第二阶段：核心标注管线

**目标**：完成一条完整的标注链路（打开图片 → 画布显示 → 标注 → 撤销重做 → 复制/保存）

### 步骤

1. 图片加载模块（PNG / JPG / BMP / GIF 静态帧 / WebP）
2. 画布显示（自适应窗口、缩放、拖拽平移）
3. 标注图元：矩形框、椭圆框、箭头、自由画笔
4. 文字工具（字号/颜色调整）
5. 马赛克/模糊工具
6. 序号标记（递增圆圈）
7. 撤销/重做（命令栈）
8. 复制到剪贴板 + 保存文件

### 产出

- 命令行可用的核心标注功能
- 验证标注效果（复制/保存后与原图叠加正确）

---

## 第三阶段：工作目录模块

**目标**：类似 VSCode 的侧边栏工作区

### 步骤

1. 打开工作目录（菜单 / 快捷键 / 拖拽文件夹）
2. 文件树浏览（文件夹嵌套展开/折叠）
3. 缩略图生成与 SQLite 缓存索引
4. 列表视图 / 网格视图切换
5. 图片状态标记（未处理 / 已标注 / 已忽略）
6. 过滤与排序（文件名、修改时间、标注状态）
7. 最近工作区 + 工作区状态持久化

### 产出

- 工作目录面板可用，支持万张图片流畅浏览

---

## 第四阶段：功能联调

**目标**：系统集成，形成完整 App

### 步骤

1. 剪贴板粘贴（Ctrl+V）自动加入当前工作目录
2. 拖拽导入
3. 系统右键菜单"用本工具打开"
4. 全局快捷键呼出
5. 多工作区标签页切换
6. 批量导出（工作目录内所有已标注图片）
7. 系统分享

### 产出

- 完整可用的图片标注 App

---

## 第五阶段：打磨与优化

**目标**：提升稳定性、减小体积、完善体验

### 步骤

1. 虚拟化列表（万张图片滚动流畅）
2. 内存映射读取大图（mmap）
3. 热启动守护进程（几百 KB 微守护）
4. 体积优化（裁剪依赖、strip、单一可执行文件）
5. 多系统真机测试（Win10 / Win11）
6. Bug 修复

### 产出

- 发布就绪安装包（< 5MB）
