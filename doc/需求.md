# PhotoAnnotator — 需求文档 v1.0

## 项目概述

一款轻量级桌面图片标注工具，面向**软件测试人员**。核心场景：测试人员在手机上测试软件时发现错误并截图，截图通过微信、钉钉等办公软件（或拖拽/粘贴）传到电脑后，需要像 Snipaste 一样在图片上快速圈出错误位置、添加箭头和文字说明，再反馈到 bug 报告。然而 Snipaste 等截图工具无法直接作用于这些"已有图片"，测试人员不得不在多个工具间来回切换，流程割裂、效率低下。

本工具补齐这一能力缺口，并引入类似 VSCode 的工作目录机制，让测试人员以 **"项目/文件夹"为单位**组织和管理待标注图片——例如一个测试任务、一个版本对应一个文件夹，截图集中存放、集中标注、进度一目了然。项目从零搭建。

### 目标用户
- 手机端测试软件、需要整理和标注错误截图的**测试人员**（核心用户）
- 需要快速对接收图片进行圈点、箭头、文字说明的团队协作场景用户
- 需要批量处理同一目录下多张图片的素材整理人员

## 技术栈

| 层                  | 技术                                     |
| -------------------- | ---------------------------------------- |
| **UI / 业务逻辑**    | Rust                                     |
| **GUI 框架**         | Slint（备选 Iced）                       |
| **绘图引擎**         | resvg / TinySkia（纯 Rust 2D 渲染）      |
| **状态持久化**       | SQLite                                   |
| **构建工具**         | Cargo + rustup                           |
| **IDE**              | VSCode + rust-analyzer                   |
| **最低系统**         | Windows 10 (x64)，后续考虑 macOS         |

### 各技术角色分工
| 组件           | 职责                               |
| -------------- | ---------------------------------- |
| **Slint**      | 窗口、菜单栏、文件树、画布等 UI 渲染 |
| **TinySkia**   | 画布 2D 绘制（矩形/椭圆/箭头/画笔/马赛克） |
| **SQLite**     | 缩略图缓存、标注层数据、最近工作区索引 |
| **系统 API**   | 剪贴板、拖拽、右键菜单、全局快捷键  |

## 功能需求
### 1. 工作目录（类似 VSCode 侧边栏）
- 打开工作目录：通过菜单 / 快捷键 / 拖拽文件夹打开一个本地目录作为"工作区"
- 文件树浏览：左侧面板以树形结构展示工作目录下的所有图片文件，支持文件夹嵌套展开/折叠
- 缩略图预览：文件树中每个图片文件显示缩略图 + 文件名，支持"列表视图"和"网格视图"切换
- 图片状态标记：每张图片可标记状态（未处理 / 已标注 / 已忽略），以颜色图标区分，方便追踪进度
- 过滤与排序：支持按文件名、修改时间、标注状态排序和筛选
- 最近工作区：自动记录最近打开过的工作目录，下次启动可快速恢复
- 多工作区：支持同时打开多个工作目录，通过标签页切换（类似 VSCode 多根工作区）

### 2. 图片导入
- 支持从剪贴板直接粘贴图片（Ctrl+V），粘贴后自动加入当前工作目录
- 支持拖拽图片文件到应用窗口
- 支持通过文件选择器打开本地图片
- 支持通过系统右键菜单"用本工具打开"
- 支持常见图片格式：PNG、JPG、BMP、GIF（静态帧）、WebP

### 3. 标注工具栏

| 工具 | 说明 |
|------|------|
| 矩形框 | 拖拽绘制矩形，用于圈选区域 |
| 椭圆框 | 拖拽绘制椭圆 |
| 箭头 | 拖拽绘制带箭头的线条 |
| 自由画笔 | 手绘线条，可调粗细和颜色 |
| 文字 | 点击后输入文字，支持字号和颜色调整 |
| 马赛克/模糊 | 对敏感区域进行遮挡处理 |
| 序号标记 | 点击自动添加递增序号圆圈 |
| 撤销/重做 | 支持多步撤销和重做 |

### 4. 输出与分享
- 一键复制标注后的图片到剪贴板（Ctrl+C）
- 保存到本地（支持选择格式和路径，默认覆盖保存到工作目录）
- 批量导出：对工作目录中所有已标注图片统一导出
- 直接调用系统分享功能发送

### 5. 交互体验
- 冷启动 < 1 秒（目标 < 100ms）
- 全局快捷键呼出（可自定义）
- 标注完成后自动复制到剪贴板（可配置）
- 工作目录内支持方向键 / 快捷键快速切换上/下一张图片
- 窗口自适应图片大小，支持缩放和拖拽平移
- 工作区状态持久化：关闭后重新打开自动恢复上次的工作目录和浏览位置

### 6. 极简模式（沉浸式全键盘操作）

测试人员批量标注时，UI 本身也是干扰。极简模式隐藏所有界面元素，只保留画布，**全部操作通过键盘完成**：

- **一键进入/退出**：默认快捷键 `Ctrl+M`（或 `Tab`，可配置），进入后隐藏菜单栏、工作目录侧边栏、标注工具栏、状态栏，仅保留图片画布
- **沉浸式标注**：画布全屏居中，窗口自适应图片大小，无任何 UI 干扰
- **全键盘操作**：工具切换、撤销/重做、复制/保存、切换图片、缩放/平移均通过快捷键完成（详见技术规范快捷键表）
- **快捷键帮助浮层**：按 `H` / `?` 呼出半透明快捷键列表，再次按下或数秒后自动隐藏
- **状态浮层**：当前图片名、标注进度等信息以半透明浮层显示，鼠标/按键操作时短暂出现，静止后隐藏
- **安全退出**：`Esc` 优先取消当前绘制操作，无绘制时再按一次退出极简模式（行为可配置）
- **数据无缝衔接**：极简模式与完整模式实时共享同一份标注数据，切换模式不丢失任何标注进度

## UI 设计（"清浅"风格）
- 纯白背景，大面积留白
- 极细分割线，减少视觉噪音
- 线性图标，小尺寸，克制
- 圆角矩形轮廓按钮
- 淡蓝色作为强调色（按钮、选中态、进度条）

### 页面结构
| 页面         | 内容                                   |
| ------------ | -------------------------------------- |
| **主窗口**   | 菜单栏 + 工作目录侧边栏 + 标注画布 + 状态栏 |
| **工作目录面板** | 文件树 + 缩略图 + 状态标记 + 过滤排序 |
| **标注画布** | 标注工具栏 + 图片画布（缩放/平移）     |
| **极简模式** | 仅图片画布 + 半透明状态/帮助浮层，全键盘操作 |
| **设置面板** | 快捷键、自动复制、输出配置             |

## 非功能需求
- 从零搭建项目
- 安装包体积 < 5MB，空闲内存 < 15MB
- 冷启动 < 100ms，静止 CPU 占用趋近 0%
- 离线可用：无需联网即可使用全部功能
- 无账号、无广告、无网络权限
- 数据安全：标注信息独立存储，不修改原始图片文件

## 版本规划

| 版本 | 范围 | 预计周期 |
|------|------|----------|
| MVP | 剪贴板粘贴 + 基础标注（矩形/箭头/文字）+ 复制到剪贴板 | 2-3 周 |
| V1.0 | 完整标注工具 + 文件导入导出 + 全局快捷键 | 4-6 周 |
| V1.5 | 工作目录（文件树 + 缩略图 + 状态标记）+ 快捷键切换图片 | 3-4 周 |

## 成功指标

- 从"接收错误截图"到"标注完成复制"全流程 < 15 秒
- 一次测试任务（一个工作目录）的错误截图集中管理，标注进度一目了然
- 标注工具覆盖测试人员日常 90% 以上的图片标注场景
- 工作目录内批量标注效率提升 50% 以上（相比逐张打开图片标注）

# 实现进度同步 v1.3（2026-09-08）

> 交互调整：移除「浏览」工具（体验反馈：放大后框选/输入文字再移图需切浏览太繁琐）。

## 变更

| 项 | 旧 | 新 |
|----|----|----|
| 平移方式 | 浏览工具下左键拖动 | **任意工具下按住中键或右键拖动**（左键永远是当前工具操作） |
| 浏览工具 | 工具栏按钮 + 快捷键 0 + Tool::Browse | **彻底移除**；工具 id 重排：0 矩形/1 椭圆/2 箭头/3 画笔/4 文字 |
| 启动默认工具 | 浏览 | 矩形（active-tool=0） |
| 快捷键 | 0-5 / r,o,a,p,t | **1-5** / r,o,a,p,t（1=矩形…5=文字，键位习惯保留） |
| 滚轮缩放 | 任意工具 | 不变（任意工具） |
| 画布提示 | — | 工具条右侧常驻提示「中键/右键拖动 = 平移 · 滚轮 = 缩放」；切工具状态栏附提示 |

## 备注

- 平移需在自由模式下进行：fit 模式下首次中/右键按下会自动固化为自由模式（无跳变）
- 中/右键拖动前若文字输入框打开，草稿直接丢弃（不误提交），避免平移后锚点错位
- 极简模式同样适用（中/右键平移与工具快捷键无关）

# 实现进度同步 v1.4（2026-09-08）

> 修正 v1.3 的默认态：启动/切图后默认进入矩形工具不合适 → 默认「指针态」。

## 变更（相对 v1.3）

| 项 | v1.3 | v1.4 |
|----|------|------|
| 启动默认 | 矩形工具（active-tool=0） | **指针态（active-tool=-1）**：左键拖动=平移，无工具被激活 |
| 切图后 | 保留当前工具 | **自动回指针态**（apply_load_result 重置） |
| 工具选择 | 点击进入、无退出途径 | 工具按钮为 **toggle**（checked 高亮当前工具；再点同按钮退出回指针态） |
| Esc 层级 | …取消绘制 > 退出极简 | …取消绘制 > **退出当前工具回指针态** > 退出极简 |

## 完整交互模型（当前）

- 指针态（默认/切图后）：左键拖动平移；无绘制/无文字落点
- 标注工具（矩形/椭圆/箭头/画笔/文字）：左键=绘制或文字落点；**中键/右键=平移**（任意状态可用）
- 退出工具：再点当前工具按钮 或 Esc（无绘制时）
- 启动/切图自动回指针态；滚轮缩放任意状态可用

# 实现进度同步 v1.6（2026-09-09）

> 文件管理：图片重命名、保存覆盖原图、GUI 打开目录、目录打开防卡顿（高清图多场景）。

## 新增 / 变更

| 功能 | 说明 |
|------|------|
| 图片重命名 | 列表/网格**右键图片行** → 浮层改名（Enter 确认/Esc 取消）；非法字符与重名拒绝；**扩展名强制一致**（防格式混淆）；磁盘与标注库同步（file_id 不变） |
| 保存 = 覆盖原图 | Ctrl+S 直接写回原文件（PNG 无损 RGBA；JPG/WebP/BMP/GIF 转 RGB 有损重压缩），**不再另存 `_annotated.png`**；保存=提交点（撤销重置、标注烧入原图、DB 标注清空防双重叠加）；保存后台线程执行不卡 UI |
| 「打开」目录 | 侧边栏「打开」按钮 → 系统文件夹选择（Windows 原生 SHBrowseForFolder，零新依赖）→ 打开为工作区 |
| 目录打开性能 | 缩略图后台串行生成 + 增量回填（不阻塞列表）；DB 批量 upsert/状态查询；大目录/高清图多不卡顿 |

## 备注（产品决策变更）

- ⚠️ 旧非功能需求「标注信息独立存储，不修改原始图片文件」**已作废**（用户确认覆盖保存）；原图被标注后不可逆
- 标注 JSON 仍存 DB 用于未保存前的切图恢复；保存后清空（标注已入图）
- 无网络环境下 rfd 不可用 → 目录对话框用系统原生 API 实现（跨平台预留 cfg）

# 实现进度同步 v1.7（2026-09-11）

> 真机体验反馈修复：排序能力、异常 PNG 兼容、设置持久化、存储异常降级。

## 新增 / 变更

| 功能 | 说明 |
|------|------|
| 排序 | 侧边栏排序按钮循环切换 **名称/时间 × 升/降**（4 态）；子目录与图片各自排序（目录在前）；当前图保持选中；模式持久化 |
| PNG 兼容 | 解码改为按**文件内容嗅探格式**（`with_guessed_format`），扩展名与实际内容不符的图片不再报 `Invalid PNG signature`（加载与缩略图两处） |
| 设置持久化 | 新增 `settings` 表：**上次工作区**（无参数启动自动恢复）、**排序模式**、**列表/网格视图** |
| 存储降级 | 数据库不可用（权限/只读/占用）时不再启动崩溃：降级运行 + 状态栏提示，标注与设置不落库 |

## 备注
