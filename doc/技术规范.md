# 技术规范

## 目标平台

- **最低系统**：Windows 10 (x64)
- **目标系统**：Windows 10/11，后续考虑 macOS
- **安装包体积**：< 5MB
- **空闲内存**：< 15MB
- **冷启动时间**：< 100ms

## Rust 工具链

- **IDE**：VSCode + rust-analyzer 扩展
- 编译器：rustc stable（rustup 管理）
- 编译目标：`x86_64-pc-windows-msvc`
- Release 优化配置（Cargo.toml）：

```toml
[profile.release]
opt-level = 3
lto = "fat"
codegen-units = 1
panic = "abort"
strip = true
```

- 依赖最小化：零依赖静态链接，所有依赖库打包进单一可执行文件
- 不使用 Electron / Chromium 等 Web 技术栈

## GUI 框架：Slint

- 版本：1.x
- 渲染后端：Skia（GPU 加速），Software 渲染回退
- UI 定义：`.slint` 声明式文件（UI 与业务逻辑分离）
- 无框窗口 + 自绘 UI：去除系统默认标题栏和边框，GPU 直接绘制控件

### 窗口结构

```
主窗口
├── 菜单栏（文件 | 编辑 | 视图 | 帮助）
├── 工作目录侧边栏（文件树 / 网格视图，可折叠）
├── 标注画布（图片 + 标注层，支持缩放/平移）
└── 状态栏（当前图片 2/15 | 已标注 3 | 未处理 12）
```

## 绘图引擎：TinySkia

- 标注图元：矩形、椭圆、箭头、折线、文字、马赛克
- 坐标空间：图片像素坐标；缩放/平移通过变换矩阵实现，标注数据不随视图变换
- 撤销/重做：命令模式（Command Stack），矢量数据入栈
- 标注层与原始图片分离存储，仅选中图片时解析对应标注层

## 存储方案（SQLite）

- 数据库位置：`%APPDATA%/PhotoAnnotator/annotator.db`
- 表结构：

| 表            | 用途                         |
| ------------- | ---------------------------- |
| `workspaces`  | 最近工作区（路径、最后访问时间） |
| `files`       | 图片索引（路径、尺寸、修改时间、状态） |
| `annotations` | 标注层数据（JSON，矢量路径 + 样式 + 序号） |
| `thumbnails`  | 缩略图缓存（低分辨率位图）   |

- 标注数据格式：JSON（图元类型、坐标、样式、序号）
- 首次扫描工作目录时生成低分辨率缩略图并建立索引，再次打开直接读缓存

## 启动优化

- **懒加载**：启动仅加载核心 UI 线程；文件树扫描、缩略图生成放入后台线程池
- **内存映射文件**：大图片/大批量文件使用 mmap 读取，避免一次性载入内存
- **热启动守护**：提供几百 KB 的后台微守护进程，按快捷键时主程序从内存瞬间唤醒

## 列表性能

- **虚拟化列表**：文件树仅渲染视口内可见的缩略图元素，滚动时复用节点
- 万张图片场景下内存占用维持在极低水平

## 系统集成

| 能力         | 方案                                     |
| ------------ | ---------------------------------------- |
| 剪贴板       | Win32 剪贴板 API（读取/写入位图，Ctrl+V/Ctrl+C） |
| 拖拽导入     | 窗口注册 DropTarget                      |
| 右键菜单     | 注册"用本工具打开"（HKCU\Software\Classes） |
| 全局快捷键   | `RegisterHotKey` (Win32)                 |
| 文件格式     | PNG / JPG / BMP / GIF（静态帧）/ WebP    |

## 快捷键表

快捷键统一由键盘事件层分发：完整模式与极简模式共享同一套按键语义，仅影响 UI 显隐。所有快捷键可在设置面板自定义。

### 全局（两种模式通用）

| 快捷键       | 功能                       |
| ------------ | -------------------------- |
| `Ctrl+Shift+A` | 全局呼出工具窗口（后台时） |
| `Ctrl+M`     | 切换极简模式               |
| `Tab`        | 切换极简模式（备用）       |
| `Ctrl+V`     | 粘贴图片到当前工作目录     |
| `Ctrl+C`     | 复制标注后图片到剪贴板     |
| `Ctrl+S`     | 保存标注后图片             |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做          |

### 极简模式（沉浸式全键盘）

| 快捷键        | 功能                       |
| ------------- | -------------------------- |
| `R` / `O` / `A` / `P` / `T` / `M` / `N` | 切换工具：矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 / 序号 |
| `←` / `→`     | 切换上一张 / 下一张图片     |
| `+` / `-`     | 放大 / 缩小                 |
| `0`           | 适应窗口                   |
| `H` / `?`     | 呼出 / 隐藏快捷键帮助浮层   |
| `Esc`         | 取消当前绘制；无绘制时退出极简模式 |
| `Space`+拖拽  | 平移画布（同完整模式）     |

### 事件分发规则

- 极简模式下命中 UI 隐藏，按键直接进入标注命令队列
- `Esc` 优先级：取消当前绘制 > 关闭帮助浮层 > 退出极简模式
- 极简模式切换仅更新 UI 显隐状态，标注数据与视图状态（缩放/平移/当前图片）完全共享
