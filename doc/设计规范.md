# 设计规范

## 设计原则（"清浅"风格）

- 极致简约，功能优先
- 大面积留白，减少视觉噪音
- 信息层级清晰，一眼可读
- 不追求炫酷动画，过渡自然即可

## 色彩系统

| 用途         | 色值       | 说明                         |
| ------------ | ---------- | ---------------------------- |
| 主背景       | `#FFFFFF`  | 纯白                         |
| 面板背景     | `#F8F9FA`  | 浅灰，侧边栏/工具栏微妙区分  |
| 主文字       | `#212121`  | 近黑色                       |
| 辅助文字     | `#757575`  | 灰色                         |
| 强调色       | `#4A90D9`  | 淡蓝（按钮/选中态/进度条）   |
| 分割线       | `#E0E0E0`  | 极细 0.5px                   |
| 成功         | `#4CAF50`  | 绿色（完成提示）             |
| 错误         | `#F44336`  | 红色                         |
| 状态-已标注  | `#4A90D9`  | 蓝色圆点                     |
| 状态-未处理  | `#9E9E9E`  | 灰色圆点                     |
| 状态-已忽略  | `#BDBDBD`  | 浅灰圆点（淡化）             |

## 字体规范

| 层级   | 大小   | 字重     | 用途                     |
| ------ | ------ | -------- | ------------------------ |
| 标题   | 20px   | Medium   | 页面标题                 |
| 正文   | 14px   | Regular  | 文件树、按钮文字         |
| 辅助   | 12px   | Regular  | 图片信息、状态说明       |
| 小字   | 11px   | Regular  | 文件大小标签             |

## 间距规范

| 类型         | 值    | 用途               |
| ------------ | ----- | ------------------ |
| 页面边距     | 16px  | 画布四周留白       |
| 面板间距     | 12px  | 侧边栏项之间       |
| 元素间距     | 8px   | 工具栏图标之间     |
| 紧凑间距     | 4px   | 缩略图与文字之间   |

## 圆角规范

| 元素       | 圆角   |
| ---------- | ------ |
| 按钮       | 8px    |
| 卡片       | 6px    |
| 输入框     | 6px    |
| 缩略图     | 4px    |

## 图标

- 线性风格（outlined），尺寸 16px
- 颜色：`#757575`（普通）/ `#4A90D9`（激活态）

## 按钮样式

- 实心按钮（强调操作）：淡蓝背景 + 白色文字
- 轮廓按钮（次要操作）：淡蓝描边 + 淡蓝文字
- 高度：32px，最小宽度：80px
- 按压态：颜色加深 10%

### 极简模式 (minimal_mode.slint)

进入方式：`Ctrl+M` / `Tab`。进入后隐藏菜单栏、侧边栏、工具栏、状态栏，仅保留画布。

```
┌────────────────────────────────────────────┐
│                                            │
│                                            │
│             图片画布（全屏居中）            │
│      （自适应窗口大小，无任何 UI 干扰）     │
│                                            │
│                                            │
│                                            │
├────────────────────────────────────────────┤
│  [2.png · 登录失败 · 已标注 3 处]          │  ← 状态浮层（半透明，静止自动隐藏）
└────────────────────────────────────────────┘
```

快捷键帮助浮层（按 `H` / `?` 呼出，半透明深色卡片，再按或 5 秒后消失）：

```
┌─────────────────────────────────────────────┐
│  快捷键            (H 隐藏)                  │
│  ─────────────────────────────────────────  │
│  工具   R 矩形  O 椭圆  A 箭头  P 画笔       │
│         T 文字  M 马赛克  N 序号             │
│  编辑   Ctrl+Z 撤销   Ctrl+Y 重做            │
│  输出   Ctrl+C 复制   Ctrl+S 保存            │
│  导航   ← / → 切换图片    H 帮助    Esc 退出 │
│  视图   + / - 缩放    0 适应窗口             │
└─────────────────────────────────────────────┘
```

- 背景：`#F8F9FA`（浅灰，突出图片本身）
- 状态浮层：左下角，半透明白底 `rgba(255,255,255,.85)` + 细边框
- 帮助浮层：居中偏右，`rgba(33,33,33,.88)` 深色底 + 白字
- 所有浮层不遮挡图片主体，鼠标/按键交互时短暂浮现，静止 3 秒后淡出
