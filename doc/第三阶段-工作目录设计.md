# 第三阶段：工作目录模块 — 设计文档

## 目标

测试人员以"项目/文件夹"为单位组织待标注截图：打开一个目录 → 侧边栏看到全部图片（缩略图+状态）→ 点击切换标注 → 标注随图片持久化，切走切回不丢。

## 布局（对齐 doc/设计规范.md 主窗口）

```
VerticalLayout
├── 工具条 ────────────── (极简模式隐藏)
├── HorizontalLayout (stretch)
│   ├── workspace-sidebar（240px，极简模式隐藏）
│   │   ├── 当前目录路径（点击返回上级）
│   │   ├── 图片列表 ListView（缩略图 48px + 文件名 + 状态点）
│   │   │    └── 子目录 → 双击进入（Phase 3）
│   │   └── [列表/网格] 切换（Phase 3）
│   └── canvas-area（右，原交互不变）
└── 状态栏 ────────────── (极简模式隐藏)
```

## 形态决策

- **目录导航式**（替代真树）：ListView 虚拟化 + 双击进子目录 + 面包屑返回；真树留作增强
- 图片列表项显示：缩略图（SQLite 缓存）、文件名、状态点（未处理灰 / 已标注蓝 / 已忽略浅灰）

## 数据流

```
打开目录(命令行/对话框)
  → workspace::scan 收集图片（扩展名过滤 + 文件名排序）
  → 缩略图生成（image crate thumbnail → PNG，thumbnails 表缓存）
  → 填充 Slint file-list model（FileEntry）

点击列表项
  → 保存当前图片标注（annotations 表 JSON）
  → 加载新图（原图+尺寸+RGBA）
  → 读取该图历史标注还原（store + overlay + 文字 model）
  → fit 模式重置

保存/复制 按钮 → 合成导出（不变）；当前文件状态 → done（files.status）
```

## 存储（doc/技术规范.md 表结构落地）

| 表 | 用途 | 本阶段函数 |
|----|------|-----------|
| `workspaces` | 最近工作区 | add/update last_opened |
| `files` | 图片索引 + 状态 | upsert、set_status |
| `annotations` | 标注层 JSON | save(整 store JSON)、load |
| `thumbnails` | 缩略图 PNG 缓存 | get/set |

- 标注序列化：serde/serde_json（Annotation 枚举 tag="type"）
- DB 路径：`%APPDATA%/PhotoAnnotator/annotator.db`（不变）

## 模块划分（开发规范目录结构）

```
src/
├── workspace/       # 新增：scan(目录扫描) + thumb(缩略图)
├── storage/db.rs    # 扩展：files/annotations/workspaces CRUD
├── canvas/          # annotation 加 serde；其余不变
└── main.rs          # 状态扩展：files/current_index/workspace_dir
```

## 分步

- **P1**：布局改造（侧边栏壳）+ 开目录 + 扫描列表 + 点击切图 ✅
- **P2**：标注持久化（serde + DB）切图不丢 + 状态自动 done ✅
- **P3**：双击子目录/面包屑、列表网格切换、最近工作区 ✅（2026-09-08）
  - 子目录混排（FileEntry.kind）+ 双击识别（Rust 时间戳）；面包屑点击跳层
  - 网格 = GridLayout 重复 Row 三列（非虚拟化 + ScrollView；虚拟化网格后置 P4）
  - 最近工作区：workspaces 表倒序 + 「最近」浮层面板
- P4：过滤排序、完整状态 UI（后续；含空目录清画布、虚拟化网格）

## 风险与对策

| 风险 | 对策 |
|------|------|
| Slint ListView 用法/缩略图 image 字段 | 先小模型验证；缩略图后置批量 |
| 切图竞态（快速连点） | P2 已落地：后台解码+序号队列（seq 丢弃过期）+ 预取 ±2（P3 起目录变更清解码缓存） |
| main.rs 膨胀 | workspace 模块收拢 IO；controller 重构留待收尾 |
| serde/rfd 新依赖下载 | 开发者终端编译（约定） |
| 网格虚拟化 | P3 网格为非虚拟化（GridLayout 重复 Row + ScrollView）；万张场景后置 P4 虚拟化网格 |
