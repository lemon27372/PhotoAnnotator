# 开发规范

## 语言与编码

- **Rust 代码**：遵循 rustfmt 默认格式 + clippy 规范，UTF-8 编码
- **Slint 文件**：遵循官方格式，UTF-8 编码
- 缩进：4 空格（Rust），2 空格（Slint / TOML）
- 行尾：LF

## 命名规范

| 类型             | 规范                    | 示例                        |
| ---------------- | ----------------------- | --------------------------- |
| crate / 模块     | snake_case              | `photo_annotator`           |
| 结构体 / 枚举    | UpperCamelCase          | `AnnotationLayer`           |
| 函数 / 变量      | snake_case              | `draw_arrow()`              |
| 常量             | SCREAMING_SNAKE_CASE    | `MAX_UNDO_STEPS`            |
| Slint 组件       | UpperCamelCase          | `WorkspaceSidebar`          |
| Slint 属性       | kebab-case              | `stroke-width`              |
| 数据库表名       | snake_case              | `annotations`               |

## 目录结构规范

```
PhotoAnnotator/
├── src/
│   ├── main.rs              # 入口（含热启动唤醒）
│   ├── ui/                  # Slint 组件绑定与页面逻辑
│   ├── workspace/           # 工作目录（文件树/缩略图/状态/最近工作区）
│   ├── canvas/              # 画布与标注引擎
│   │   ├── tools/           # 各标注工具（矩形/箭头/画笔/文字/马赛克…）
│   │   └── render.rs        # TinySkia 渲染
│   ├── storage/             # SQLite 持久化
│   ├── system/              # 剪贴板/拖拽/右键菜单/全局快捷键
│   └── util/                # 工具函数
├── ui/                      # .slint 声明文件
├── doc/                     # 项目文档
├── devlog/                  # 开发日志
├── assets/                  # 图标、字体资源
└── Cargo.toml
```

## Git 提交规范

- 格式：`<type>: <简短描述>`
- type：feat / fix / refactor / docs / chore / build
- 示例：`feat: 添加工作目录文件树`

## 代码审查要点

- 每个功能完成后自测通过再提交
- 不引入无用依赖（用 `cargo machete` / `cargo udeps` 检查）
- 保持体积与性能意识（安装包 < 5MB 红线）

## 开发原则

- Cargo 工具链可自动生成/配置的内容（`cargo fmt`、`cargo clippy`、`cargo nextest`），优先使用工具完成
- UI 优先用 Slint 声明式实现，避免手写渲染逻辑
- 耗时操作（文件扫描、缩略图生成）一律放后台线程，禁止阻塞 UI 线程

## IDE 配置（VSCode）

推荐扩展清单见项目根 `.vscode/extensions.json`，VSCode 打开项目时会自动提示安装。

- **必装扩展**：
  - `rust-lang.rust-analyzer` — Rust 语言服务器（补全/跳转/诊断）
  - `tamasfe.even-better-toml` — Cargo.toml 语法高亮与校验
  - `slint.slint` — Slint 官方插件（.slint 文件高亮/预览）
  - `vadimcn.vscode-lldb` — CodeLLDB 调试（cargo run 断点调试）
- **推荐扩展**：
  - `usernamehw.errorlens` — 错误内联提示
  - `eamodio.gitlens` — Git 增强（历史/责备）
  - `qwtel.sqlite-viewer` — SQLite 数据库可视化
  - `serayuzgur.crates` — Cargo.toml 依赖版本提示
  - `MS-CEINTL.vscode-language-pack-zh-hans` — 中文界面语言包
- rust-analyzer 配置：`"rust-analyzer.cargo.allFeatures": true`
- 调试：使用 CodeLLDB 启动 `cargo run`，支持断点/变量监视
- 构建运行：统一使用 VSCode 终端执行 `cargo build` / `cargo run`，避免手动配置构建脚本

## 文件编码

- 所有源文件保存为 **UTF-8 without BOM**
- 不允许出现 \uFEFF（BOM）字符
- 新建文件使用编辑器默认 UTF-8 保存
- 出现 `非法字符: '\uFEFF'` 错误时，用 `[System.IO.File]::ReadAllBytes` 去除前 3 字节
