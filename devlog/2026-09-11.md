## 今日事项

### 1. 排序功能（侧边栏）

- [x] 侧边栏行 2 新增**排序按钮**（label 显示当前模式：`名↑ / 名↓ / 时↑ / 时↓`），点击循环切换

- [x] 切换排序后写 DB settings（持久化）

### 2. PNG 打不开修复（内容嗅探解码）

- [x] 根因：`image::open(path)` 按**扩展名**选解码器 → 扩展名与实际内容不符（如 jpg 内容存成 .png）时报 `Invalid PNG signature`
- [x] 修复：`canvas/loader.rs::decode_image` 与 `workspace/thumb.rs::gen_thumbnail_png`
  改用 `ImageReader::open(path)?.with_guessed_format()?.decode()`（按**文件内容**嗅探格式）

### 3. 设置持久化（重启保留）

- [x] DB 新增 `settings(key, value)` 表 + `get_setting/set_setting`
- [x] 持久化项：
  - `last_workspace`：**无参数启动自动恢复上次工作区**（目录不存在则提示用「打开」选择）
  - `sort_mode`：排序模式（0 名↑ / 1 名↓ / 2 时↑ / 3 时↓）
  - `view_mode`：列表 / 网格视图（新增 `view-changed` 回调，Rust 落库）
- [x] 命令行带参打开时仍以参数为准

### 4. 健壮性：数据库不可用不再崩溃（诊断中发现的隐患）

- [x] 现象复现：沙箱环境禁止写 `%APPDATA%` → SQLite 只读 → 新增 `settings` 建表触发写失败 →
  `storage::init()?` 直接返回 Err → **程序启动即退出**
- [x] 修复：`init()` 失败降级运行（`db_ok=false`），状态栏提示「数据存储不可用（权限/只读），
  本次标注与设置不会被记住」；DB 相关调用本身已有容错（读返回 None / 写静默）
- [x] 说明：真机无此权限限制，此项属预防性改进
