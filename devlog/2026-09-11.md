## 追加：真机测试缺陷修复 — 刷新机制（重大问题）

> 真机反馈：① 文件夹新增图片不显示；② 标注保存后画布/缩略图仍显示原图 —— 都需"返回上级再进入"才刷新。

### 根因定位（三条）

1. **保存后画布显示原图**（核心）
   - 画布 = Slint `current-image`（原图位图）+ overlay（标注层）。保存收尾时只清空了 overlay、更新了内存基底 `image_rgba`，
     **未替换 `current-image`** → 画布呈现的仍是旧原图位图（标注"消失"）；切走再切回因重新解码才正确
2. **缩略图轮次失效漏洞**
   - 缩略图后台任务以"轮次 round"作废旧结果，但 `round` 仅在**有新任务时**递增；
     保存触发缩略图重建时，保存前发起的在途旧任务可能携带**同一轮次**返回，把旧缩略图写回内存与 DB（列表显示原图）
   - 同类风险：目录切换时若新目录全部命中缓存（无新任务 → round 不变），旧目录任务结果会按索引落到新目录（串图）
3. **缺少重新扫描入口**：外部新增/删除文件后，列表不会重新扫描磁盘（`files` 只在打开目录/进入子目录/面包屑切换时生成）

### 修复

- [x] **保存收尾同步画布**：合成结果同时写入 `set_current_image`（画布与内存基底一致）
- [x] **`invalidate_thumbs()`**：递增轮次 + 清空结果队列；在**保存成功**与**目录切换/刷新**时调用，彻底防旧任务回写
- [x] **手动刷新**：侧边栏标题行新增「刷」按钮 + **F5** 快捷键 → `refresh_current()`
  - 重新扫描磁盘（dirs + files + 批量 upsert file_ids）
  - **保留**：当前图片选中（按路径重定位）、已生成缩略图（按路径重映射到新索引，避免刷新即全量重建）
  - 当前图已被删除时清空选中状态并提示，画布内容保留
- [x] **目录变化自动刷新**：新增 2s 定时器检查当前目录 mtime（外部增删文件会更新目录 mtime）
  - 检测到变化 → 静默刷新；可见数量变化时状态栏提示 `旧 → 新 张`
  - 绘制中 / 文字输入 / 任一浮层打开时**跳过本次**（不打扰操作）

### 验证

- `cargo check` / `cargo build` 通过；`cargo test` **7 项全过**（既有测试未受影响）
- 真机复测（开发者确认）：保存后画布与缩略图即时更新；外部新增图片 2 秒内自动出现；F5/「刷」按钮可手动刷新
