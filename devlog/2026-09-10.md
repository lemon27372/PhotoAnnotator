## 今日事项

### 打开目录卡顿修复：DB 批量写入事务化

- [x] **现象定位**：Release 版、50~300 张中量目录，打开瞬间主线程冻结几秒（缩略图后台化已生效但未解决）
- [x] **根因**：`upsert_files_batch` 逐条 INSERT 处于 **autocommit 模式** → N 张图 = N 次事务提交 = N 次磁盘 fsync（防病毒实时扫描下每次更慢）→ 200 张 ≈ 数秒，全部在主线程同步执行
- [x] **修复**：批量入库显式 `BEGIN ... COMMIT`（单事务单次 fsync）；顺带 `file_statuses_batch` 批量读
  - 效果：打开瞬间不再冻结（开发者验证通过）
- [ ] 备注：缩略图回填的逐张 `save_thumbnail` 仍是 autocommit 写（后台线程执行，不阻塞 UI），回填速率受 fsync 影响属可接受；后续可批量落库
